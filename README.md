## 🎮 숫자 맞추기 게임 (`guess.py`)

컴퓨터가 고른 숫자를 맞혀 보는 간단한 파이썬 게임입니다.

> ⚠️ `guess.py`는 아직 추가되지 않았으며, 곧 저장소에 올라갈 예정입니다.

### 요구 사항

- Python 3

### 실행 방법

```bash
python guess.py
```

### 플레이 방법

1. 게임을 실행하면 컴퓨터가 숫자 하나를 정합니다.
2. 추측한 숫자를 입력합니다.
3. 입력한 숫자가 정답보다 큰지 작은지 힌트를 보고 다시 시도합니다.
4. 정답을 맞히면 게임이 끝납니다.
